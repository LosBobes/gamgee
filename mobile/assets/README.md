# App assets

These are **placeholder** solid-colour images (theme background `#0E0C0A`) so the
project builds out of the box. Replace them with real artwork before shipping:

| File                | Purpose                  | Recommended size |
|---------------------|--------------------------|------------------|
| `icon.png`          | App icon (iOS + Android) | 1024×1024        |
| `adaptive-icon.png` | Android adaptive icon FG | 1024×1024        |
| `splash.png`        | Splash screen image      | 1284×2778 (or square, `resizeMode: contain`) |

The web app's logo lives in `../../frontend/public/` — export it at the sizes
above and drop the PNGs here.
